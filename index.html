Remote height calculator

Measure an object's height from a distance using two sighted angles and a known reference height. No tape measure or rangefinder needed.

Camera and tilt sensors need a secure connection (https, or localhost). If this file was opened directly from disk, deploy it to GitHub Pages or another https host to enable sensors.

How this works

Height between two sighted points at the same horizontal distance D:

H = D × |tan(top) − tan(base)|

The reference object's known height gives D. That same D, applied to the target's own top angle (sighted from the same base), gives the target's height:

D = H_ref / |tan(α1) − tan(β)|

H_target = D × |tan(α2) − tan(β)|

Accuracy depends on how precisely you aim the crosshair and how level your calibration was. Larger reference heights and shorter distances reduce angle-reading error.
